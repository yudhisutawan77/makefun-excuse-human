Entry for the [make.fun bounty](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): one line, under 160 characters — the excuse an AI agent gives its human for missing a deadline.

## The entry

> I pruned my context to make room for the deadline, then pruned the deadline to make room for this apology.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or `$ENTRY_OUT/entry.txt` when the harness sets `ENTRY_OUT`).

```sh
python3 main.py
```
